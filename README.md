# EyeSpan PD（単体HTML版）

フロントカメラで瞳孔間距離（PD）を測るアプリです。`index.html` 1ファイルで動きます（アイコン用に `icon.png` を一緒に置きます）。

## GitHub Pagesでの公開手順
1. GitHubで新しいリポジトリ「eyespan-pd」を作ります
2. `index.html` と `icon.png` をアップロードします
3. リポジトリの Settings → Pages で、公開するブランチ（main）を選びます
4. 数分待つと公開されます

公開URL： https://jkj7vv2nd7-lang.github.io/eyespan-pd/

iPhoneのSafariで開いて「ホーム画面に追加」すると、専用アイコンでアプリのように使えます。

## データについて
- 測定履歴は、その端末のブラウザの中にだけ保存されます。映像は端末内でのみ処理し、外部に送信しません
- Museライブラリ版とはデータは共有されません（単体版は空の状態から始まります）

## 注意
- 顔検出の仕組みを読み込むため、初回はインターネット接続が必要です
- カメラが使えない環境では、写真アップロードからの測定が代替になります
- 医療機器ではありません。値は参考値で、正確な測定は専門家にご相談ください
